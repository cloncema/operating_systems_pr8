Программа на C, которая играет сама с собой в «угадай число». В игре участвуют два процесса (родительский и дочерний, созданный через `fork()`). Роли загадывающего и угадывающего меняются каждые 10 раундов (всего 20 раундов).

**Параметр N** — максимальное число (от 1 до N). По умолчанию `N = 100`.

## Файлы

- `task1.c` — Решение с помощью сигналов (`SIGRTMIN`, `SIGUSR1`, `SIGUSR2`).
- `task2.c` — Решение с помощью неименованного канала (`pipe`).

## Компиляция и запуск

### Задание 1 (Сигналы); Задание 2 (Неименованный канал)
```bash
gcc -Wall -o task1 task1.c
./task1 100
gcc -Wall -o task2 task2.c
./task2 100
